# FS-4 Firmware

The firmware repository for FS-4, Formula Slug's fifth electric racecar.

- Vehicle Control Unit
- Tractive Battery Board
- Steering Wheel Board
- Telemetry Peripheral Boards
- Charger

As well as a few different C++ libraries for sensors and things.

# DBC

A spreadsheet of all CAN messages and their IDs is [here](https://docs.google.com/spreadsheets/d/1xfGveZo21O96w-yZfIBUiUPRuIjSAeYAHd7m7HwQNaY/edit?usp=sharing).
